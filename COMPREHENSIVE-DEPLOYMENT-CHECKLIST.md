## 📝 ISSUE RESOLUTION GUIDE

### **Issue: Links Return 404**

**Cause:** Relative paths not working on Vercel
**Solution:**
- Use absolute paths: `/page.html` not `./page.html`
- Or use full domain: `https://ganeshglasscenter.com/page.html`
- Check file names match exactly (case-sensitive on Linux servers)

### **Issue: WhatsApp Links Don't Work**

**Cause:** Incorrect URL format
**Solution:**
- Use: `https://wa.me/919876543210?text=Message`
- Not: `wa.me` without `https://`
- Phone number must include country code

### **Issue: Forms Don't Submit**

**Cause:** No backend configured
**Solution:**
- Use Formspree, Netlify Forms, or similar
- Or set up Node.js backend on Vercel
- Store to localStorage for client-side only

### **Issue: Images Don't Show**

**Cause:** Placeholder URLs used in development
**Solution:**
- Replace placeholder.com URLs with real images
- Upload images to Vercel or CDN
- Use relative paths: `/images/photo.jpg`

### **Issue: Admin Dashboard Not Working**

**Cause:** Data stored in localStorage, cleared on deployment
**Solution:**
- Data persists in localStorage (browser storage)
- No backend database, local storage only
- Works offline, data stays in user's browser

### **Issue: Mobile Menu Not Working**

**Cause:** JavaScript not loading
**Solution:**
- Check Tailwind CSS is loaded from CDN
- Check custom JavaScript is included
- Test in browser console for errors
