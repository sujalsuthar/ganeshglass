1. Find testimonial section in HTML
2. Replace:
   - Customer name
   - Location
   - Quote text
   - Avatar initials
3. Maintain 5-star rating
4. Keep color scheme consistent

1. Replace image placeholder URLs
2. Update project title

4. Keep BEFORE/AFTER labels

2. Find embed code in settings
3. Replace `.google-reviews-embed` placeholder
4. Test embed displays correctly
