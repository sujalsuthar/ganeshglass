## 🎨 Implementation Steps

### Step 1: Find Each Image in HTML
Use Ctrl+F (or Cmd+F) to search for:
- `<img` tags
- `src="..."` attributes
- Current `alt=""` text

### Step 2: Copy New ALT Text
Find your image in the list above and copy the corresponding alt text.

### Step 3: Replace in HTML
Replace the old alt text with the new one from this guide.

### Step 4: Add Image Attributes
Make sure each `<img>` tag has:
- ✅ `width="###"` (prevents CLS)
- ✅ `height="###"` (prevents CLS)
- ✅ `loading="lazy"` (for below-fold images)
- ✅ `loading="eager"` (for hero/above-fold)
- ✅ `decoding="async"` (prevents blocking)

### Step 5: Verify
- [ ] All alt text is descriptive (40+ characters)
- [ ] Includes service keywords
- [ ] Includes location keywords
- [ ] Includes city name "Ahmedabad"
- [ ] Width and height are set
- [ ] Loading attribute is set
- [ ] Decoding attribute is set

## 💡 Quick Tips

1. **ALT Text Length:** 50-125 characters (sweet spot)
2. **Keywords:** Place most important keyword first
3. **Descriptive:** Describe what you see, not "image of"
4. **Avoid:** Keyword stuffing (Google penalizes)
5. **Mobile First:** Test on mobile (50% of traffic)
6. **Accessibility:** Screen reader friendly
7. **Google Images:** Improves image search ranking
